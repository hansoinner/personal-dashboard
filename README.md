# Personal Dashboard

A modern personal productivity dashboard built with vanilla HTML, CSS, and JavaScript.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Git
- GitHub
- GitHub Pages

## Features

- Responsive dashboard
- Sidebar navigation
- Mobile navigation
- Live clock
- Current date
- Task management
- Task completion tracking
- Task deletion
- Productivity percentage
- Progress bar
- Quick notes
- Local storage
- Quick links
- Responsive design
- Keyboard navigation
- Accessible mobile menu
